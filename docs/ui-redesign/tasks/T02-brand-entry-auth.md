# T02 品牌、入口与登录注册

## 目标

统一 Web 品牌标记、入口页、登录页和达人注册页，使首次进入的用户感到真实、清楚、可信。所有现有入口、身份校验和跳转保持不变。

## 依赖与允许文件

- 依赖：T01。
- 允许修改：`frontend/src/pages/auth/*.tsx`、对应测试、`frontend/src/styles/auth.css`、`frontend/public/favicon.svg`、`frontend/index.html`。
- 允许新增：`frontend/src/components/AppLogo.tsx`、对应测试、`frontend/public/images/brand/*` 及图片来源说明。
- 不允许修改：`App.tsx` 路由、登录/注册 API、auth store、Android 文件。

## 固定视觉规格

- 品牌名统一为“蓝鹰寄拍”。`AppLogo` 复用 Android 鹰羽勾形轮廓，提供 `full` 和 `mark` 两种尺寸，不绘制第二套图形。
- 桌面认证页为约 55% 实景图片 + 45% 表单；最大表单宽 400px，页面背景 `#F7F7FA`。
- 手机端小于 768px 时，图片成为 128px 高品牌横幅，表单从首屏 144px 后开始，左右 20px。
- 标题 28px/36px，辅助文字 14px/22px；输入和主按钮高 44px；入口选项最小高 80px、圆角 8px。
- 图片使用本地 WebP，内容为自然光真实居家/校园商品拍摄，不使用暗色服装店库存图或远程 URL。
- 功能图标只用现有图标库；入口卡图标为 20px，右箭头 16px。

## 页面要求

### `/entry`

- 保持“运营管理端”和“达人端”两个入口及当前顺序、路由。
- 标题改为明确的“进入蓝鹰寄拍”，辅助说明不超过 20 个汉字。
- 两个入口以清晰列表呈现，不做宣传卡，不增加商家入口。

### `/login`、`/admin/login`、`/talent/login`

- 保留 portal 角色校验和登录成功跳转。
- 清晰标注当前入口身份，错误提示不得让用户误以为账号丢失。
- 登录中按钮宽高不变，错误后保留手机号。

### `/talent/register`

- 保留现有字段、注册来源、API 和成功跳转。
- 文案强调“创建接单账号”，不增加收益承诺、协议字段或邀请码。
- 手机软键盘打开时提交按钮可滚动到达。
