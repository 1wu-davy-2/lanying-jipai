# T10 管理端看板、用户、提现与话术库

## 目标

统一运营看板、用户管理、提现审核和话术库的视觉密度与手机降级体验。页面保持工作型、易扫描，不套用达人端的生活方式卡片。

## 依赖与允许文件

- 依赖：T01、T03。
- 允许修改：`frontend/src/pages/admin/AdminDashboardPage.tsx`、`frontend/src/pages/admin/AdminUsersPage.tsx`、`frontend/src/pages/admin/AdminWithdrawalsPage.tsx`、`frontend/src/pages/admin/AdminScriptsPage.tsx`、对应测试、`frontend/src/styles/admin-support.css`。本页面断点写在该模块末尾。
- 不允许修改：管理 API、用户权限、实名审核字段、商家保障字段、提现状态、话术内容或路由。

## 页面要求

### 运营看板

- 关键指标使用一条响应式指标网格，不做装饰性大卡；数值、单位、时间口径清楚。
- 加载、无数据和接口错误分开；不得用 0 代替请求失败。
- 不新增图表库或虚构趋势。

### 用户管理

- 保留角色、账号状态、认证状态和关键词筛选。
- 桌面列出用户、角色、账号、认证、商家保障和操作；敏感字段继续按权限与现有脱敏显示。
- 手机摘要显示昵称/手机号脱敏、角色、账号/认证状态和“更多操作”。
- 认证审核、禁用/启用和商家保障设置分别使用清楚弹层；危险操作二次确认，不改 payload。

### 提现审核

- Tabs 和状态值保持不变；每条显示用户、金额、收款账号、中文状态和时间。
- 待审核显示通过/驳回，待转账显示登记流水；不同阶段不出现错误按钮。
- 手机摘要不得隐藏驳回原因或转账流水；收款账号按当前权限展示。

### 话术库

- 保持分类、敏感品类提示、搜索、章节、复制单条/全文和分页功能。
- 桌面使用章节侧栏+内容区；手机先章节下拉/折叠，再显示内容，不保留双栏挤压。
- 敏感品类提示必须保留自愿、拍摄边界和可拒绝原则，不弱化为普通标签。
- 移除 `window.innerWidth` 硬算 Drawer 宽度，使用 CSS/组件响应式能力。

## 视觉密度

- 页面标题 28px，表格正文 14px，辅助 12-13px；按钮高 32-40px。
- 管理端主色仍来自全局莓果色，但成功、风险、资金和信息使用各自语义色，避免整页单一色。
- 复制按钮使用 `CopyOutlined`；搜索、筛选、审核和提现使用 PRD 图标映射。
