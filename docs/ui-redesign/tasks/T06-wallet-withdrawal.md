# T06 钱包与提现

## 目标

将资金账户和提现申请改成清晰、可核对的财务体验，严格区分可提现、冻结、流水和提现状态，不增加“累计收益”等当前接口没有提供的数据。

## 依赖与允许文件

- 依赖：T03。
- 允许修改：`frontend/src/pages/wallet/WalletPage.tsx`、`frontend/src/pages/wallet/WalletPage.test.tsx`、`frontend/src/pages/wallet/WithdrawalApplyPage.tsx`、可新增对应测试、`frontend/src/styles/wallet.css`。本页面断点写在该模块末尾。
- 不允许修改：`api/wallets.ts`、提现 API、余额校验、支付宝快照行为、路由或后端金额逻辑。

## 钱包页规格

- 标题与“申请提现”构成首区；按钮为唯一主操作。
- 可提现余额为唯一主数据：桌面 32px、手机 28px，使用 `--color-money-700`。
- 处理中提现和账单笔数作为同一摘要带的次级数据，不做三张等权大卡。
- 桌面资金明细与提现记录保留表格；手机改为两组账单列表，可通过标题区切换或顺序展示，不允许页面级横向滚动。
- 流水项显示类型、正负金额、变动后余额、时间；提现项显示单号、金额、中文状态、申请时间和驳回原因。
- 金额始终两位小数、等宽数字；正负不能只靠颜色判断。

## 提现页规格

- 页面最大宽 640px，标题区包含 44px 返回按钮。
- 表单上方显示可提现余额；金额字段旁说明不能超过余额。
- 支付宝账号明确为“本次提现收款账户快照”，不得暗示提交后自动修改个人资料。
- 提交中防重复；成功后按现有逻辑返回；失败保留金额和账号。
- 余额不足、账号缺失、接口错误和审核中均给出真实说明，不新增客服或支付能力。
