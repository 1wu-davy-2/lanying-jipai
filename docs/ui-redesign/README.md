# 蓝鹰寄拍 UI 重设计文档索引

本目录用于在**不改变功能流程、权限、路由、API、数据结构和状态机**的前提下，统一网页、手机网页与 Capacitor Android 的视觉体验。目标用户假设为女性约占 85%，核心人群包括宝妈、大学生和首次参与寄拍的女性用户；设计应温和、可信、有审美，但不得将女性审美简化为粉色、可爱或低龄化。

## 文档顺序

1. [00-audit.md](./00-audit.md)：当前实现、旧设计文档与品牌资产审查。
2. [01-prd.md](./01-prd.md)：本轮重设计的产品需求、视觉系统和页面规格。
3. [02-execution-contract.md](./02-execution-contract.md)：所有实施任务共同遵守的边界、检查方式和反馈格式。
4. [tasks/README.md](./tasks/README.md)：可单独领取的实施任务、依赖与文件所有权。

## 规范优先级

- 业务行为以当前后端服务、路由、前端 API 调用和自动化测试为准。
- 本目录仅覆盖视觉、布局、文案层级、响应式和可访问性，视觉要求取代 `docs/04-frontend-design.md` 及旧达人端改版文档中的视觉部分。
- 本目录不取代数据库、接口、履约、结算、提现、权限与部署规则。
- 发现文档与代码冲突时，不得擅自“修正”业务；停止扩展并在反馈中列出冲突。
