# 蓝鹰寄拍 · 敏感品类寄拍话术（文胸 / 情趣衣物）

> **适用范围**：品牌方寄拍涉及文胸、塑身、情趣风格衣物、贴身内衣等  
> **佣金口径**：通常为普通衣物的 **3～5 倍**（以订单页显示金额为准）  
> **使用原则**：先告知品类与拍摄边界 → 自愿确认 → 再引导抢单；**可随时拒单，零惩罚话术**  
> **对象**：仅面向 **已成年（18+）** 且完成实名认证的达人  
> **与普通招新区别**：不在抖音冷启动首条私信主推此类；优先在微信/站内、已建立信任后沟通

---

## 0. 运营红线（必须先读）

### 0.1 必须做到

| 规则 | 说明 |
| --- | --- |
| 事前明示 | 接单前必须说清：品类、是否需上身试穿、是否露脸、是否出镜全身 |
| 自愿原则 | 明确「不接完全不影响评级/后续普通单」 |
| 仅限成年 | 未满 18 岁、资料存疑一律不推、不派 |
| 订单内留痕 | 品类标签、拍摄要求、佣金写在订单里，不靠口头加码 |
| 尊重边界 | 达人可只接「平铺/挂拍/手持展示」，不强迫出镜试穿 |
| 隐私保护 | 素材仅用于该订单约定用途；不引导私下加商家微信传原图 |
| 平台内沟通 | 需求变更走订单留言，避免「加钱私下拍」 |

### 0.2 禁止话术

```text
❌ 不说清楚就让人抢单
❌ 「这单简单，穿一下就行」（淡化品类）
❌ 「不拍就别做了 / 会降权」（胁迫）
❌ 「多露一点更好过审 / 买家就爱看这个」
❌ 色情挑逗、约拍私单、线下见面拍摄
❌ 向未成年/学生党重点推送此类单
❌ 用「日入」「裸赚」等刺激词包装敏感单
❌ 要求达人先垫付购买情趣用品
```

### 0.3 品类分级（对内运营用，对外用「温和表述」）

| 级别 | 对内 | 对外可说 | 常见拍摄 | 佣金参考 |
| --- | --- | --- | --- | --- |
| S1 常规内衣 | 文胸、内裤、家居服 | 贴身衣物 / 内衣寄拍 | 平铺、上身（可要求不露脸） | 约 2～3 倍普通衣 |
| S2 塑身/情趣风格成衣 | 情趣风格套装、网纱、制服风格（非裸露） | 风格化服饰 / 特殊品类寄拍 | 上身出镜要求更细 | 约 3～5 倍 |
| S3 高敏感 | 强暗示、开档等极端款 | **默认不开放**或仅白名单达人 | 需法务/运营双审 | 单独定价 |

> 对外对达人：**少用「情趣」二字开场**（易引发防备或平台敏感），优先用「特殊品类贴身衣物 / 风格化内衣寄拍」，确认意向后再精确说明款式。

### 0.4 推荐沟通路径

```text
站内/微信（已信任达人）
  → 先发「品类预告 + 是否愿意看」
  → 对方回复愿意
  → 发「拍摄边界清单 + 佣金倍数说明 + 可拒单」
  → 对方明确「可接 / 仅平铺 / 不接」
  → 仅「可接」者看到或被引导对应订单
  → 抢单前二次确认关键项
```

**不要**在抖音首条破冰里主推敏感品类。

## 1. 预告话术（是否愿意看这类单）

### 1.1 微信 / 站内 · 标准预告（推荐）

```text
嗨，先跟你同步一个品类，你看完再决定要不要看单，完全自愿：

我们会有一些【贴身衣物 / 内衣类】品牌寄拍（含文胸，以及部分风格更特别的款）。
这类单拍摄要求更细，所以佣金一般是普通衣物的大约 3～5 倍（以订单显示为准）。

重要说明：
1）只发给成年且愿意了解的达人
2）不接不影响你继续接普通单
3）可只接「平铺/不露脸」，也可以选择不上身

你方便回一个吗：
A. 可以了解，发我要求
B. 只接普通衣物
C. 再等等
```

### 1.2 更短版

```text
有一类【内衣/贴身衣物寄拍】，佣金通常比普通衣高约 3～5 倍，但拍摄边界更严，需你本人自愿。
不接完全没问题。想了解回「可以了解」，只想接普通单回「普通」。
```

### 1.3 已合作过、信任度高

```text
你之前交付比较稳定，想先问你一句（不勉强）：
品牌侧有内衣/特殊风格贴身款寄拍，佣金更高（常见约 3～5 倍普通衣），但必须事先说清是否上身、是否露脸。
你若接受「先看要求再决定」，我发边界清单；不接受当我没说，继续给你推普通单。
```

### 1.4 对方是学生党（谨慎）

```text
先确认：你是否已满 18 周岁且方便自主决定接单类型？
我们有一类贴身衣物寄拍，佣金更高，但只开放给明确自愿的成年达人。
若你更想做普通穿搭/静物，直接说「只要普通」，我不会再推这类。
```

> 未满 18 或无法确认：停止推送，仅普通品类。

## 2. 边界说明话术（对方回「可以了解」后必发）

### 2.1 完整边界清单（主话术 · 建议收藏为模板）

```text
【特殊品类寄拍说明 · 请仔细看】

一、品类
品牌寄拍可能包含：文胸、内衣套装、塑身/风格化贴身衣物等。
具体以每一单的「商品说明 + 拍摄要求」为准，下单前你能看到。

二、佣金
同类单佣金通常约为普通衣物的 3～5 倍。
最终以订单页佣金金额为准，不接受口头加价、不私下收付款。

三、拍摄方式（你可按单选择）
① 平铺/挂拍/细节图（不上身）
② 上身试穿但不露脸（出镜局部/裁切）
③ 上身试穿且需露脸/半身（要求会写在订单里）
没有写进订单的要求，你可以拒绝。

四、我们明确不要求
· 不要求裸露超出资质与订单约定
· 不要求线下见面、私单加拍
· 不要求把原图发到个人微信给陌生人
· 不要求先垫钱买样品（样品由商家寄出）

五、你的权利
· 预告阶段可直接说不接
· 看到订单后仍可不抢
· 抢单前发现与描述不符，可立即联系运营说明
· 拒绝对你后续普通单没有惩罚话术、不因此降权承诺

六、隐私与用途
素材仅用于该订单约定的商品展示/验收；
平台内沟通与上传，保留记录便于维权。

若你接受「在规则内自愿接单」，请回复：
「已知晓，可按边界接单」
若只接受平铺：回复「仅平铺」
若全部不接：回复「不接特殊品类」
```

### 2.2 佣金单独说明（对方只关心钱）

```text
关于佣金（特殊品类）：
· 因为拍摄配合度、表达分寸、退换风险更高，品牌预算通常更高
· 平台侧常见是普通衣物单的约 3～5 倍
· 例：普通衣物若一单 80～150，特殊品类可能到约 240～750 区间（举例理解，下单以页面为准）
· 结算规则不变：验收通过 → 入账 → 申请提现
· 不会因为「尺度大」再额外私下转钱；一律走订单

你更在意「高一点但要求清晰」，还是「只要普通衣」？我按你的选择匹配。
```

### 2.3 只做平铺的达人

```text
可以，很多姐妹只接「平铺/细节/挂拍」：
不上身、不露脸，按商品图规范拍清楚版型、面料、钩扣、花边即可。
这类也会标佣金（通常仍高于普通衣，但可能低于必须上身的单）。
你回复「仅平铺」后，我优先只给你看标注了平铺可完成的单。
```

### 2.4 可上身但不露脸

```text
明白。订单里我们会尽量标注：
· 需上身试穿
· 可不露脸 / 面部打码或构图避开
请你接单前再核对图片示例与文案；若商家临时要求露脸且订单未写，你有权拒绝补拍并找运营。
```

## 3. 抢单前二次确认（强烈建议）

### 3.1 站内 / 微信确认

```text
这单属于【贴身衣物/特殊品类】，抢单前请确认：

1）商品类型：【文胸 / 套装 / 其他______】
2）拍摄：【仅平铺 / 需上身 / 需露脸】
3）佣金：¥【金额】（约普通衣 X 倍，仅供参考）
4）你已满 18 岁且自愿接单：是 / 否

请直接回复：
「确认抢单」或「放弃」

放弃无需解释，不影响普通单。
```

### 3.2 一句话确认（订单多时）

```text
特殊品类单 #【订单号】｜佣金¥【】｜【平铺/上身/露脸】
自愿才抢，不抢请忽略。确认请回「确认」。
```

## 4. 达人常见顾虑 · 应答

### 4.1 「是不是很色情 / 很尴尬」

```text
理解这个担心。我们按「商品拍摄」来做，不是擦边直播。
订单会写清拍什么角度、是否上身；你也可以只接平铺。
不舒服的要求可以不接，我们更在意合规和你的边界，不在意硬推尺度。
```

### 4.2 「照片会不会被乱用」

```text
请只在平台订单内上传；不要按陌生人要求改发个人号。
用途以订单约定的商品展示/验收为主。
若遇到有人引导「加微信多拍私单」，直接拒绝并告诉我。
```

### 4.3 「家里人会看到快递」

```text
外包装一般按普通服装快递，但无法 100% 保证面单品名如何打印。
若你家庭环境不方便收贴身类包裹，建议选择不接，或只接你确定能独立签收的时段。
这点以你实际生活便利为准，我们尊重。
```

### 4.4 「会不会要我买下来」

```text
寄拍是商家寄样，按流程拍摄后寄回（订单会写清是否需寄回）。
不要求你付款购买；若有人让你先转账，一律当异常，停止并举报给我。
```

### 4.5 「佣金真有 3～5 倍吗」

```text
这是品类预算上的常见区间，用来帮你建立预期；
每一单以订单页写明的佣金为准，可能更高或略低。
我们不会用「保证 5 倍」逼你接单。
```

### 4.6 「接了以后可不可以中途不做」

```text
抢单成功后请尽量完成（涉及商家已寄样等）。
若尚未寄出、或样品与描述严重不符、或出现超出资质的违规要求：立刻在订单留言并联系运营，我们按规则处理，不让你硬扛。
所以更稳妥是：抢单前看清要求。
```

### 4.7 「我可以接，但不要把我标成情趣达人」

```text
可以。对内只做订单匹配，不会在普通招新里宣传你的个人标签。
你也可以设置「可接特殊品类 / 仅平铺 / 关闭特殊品类」，我们按你的意愿来。
```

## 5. 拒单与关闭品类（保护体验）

### 5.1 达人表示不接

```text
收到，已记录：不推送特殊品类。
你继续接普通衣物/日用品即可。
以后若改变主意，随时说「可了解特殊品类」。
```

### 5.2 达人接过一次后不想再接

```text
没问题，立刻帮你关掉特殊品类匹配。
你的普通单权益不受影响，感谢你如实说边界。
```

### 5.3 达人反感被多次推送

```text
抱歉打扰了。已停止向你发送该类预告。
若是我们话术让你不适，也可以直接说，我们会改。
```

## 6. 拍摄执行提醒（已接单达人）

### 6.1 开拍前

```text
开拍前建议：
1）再读一遍拍摄清单（件数、角度、是否上身）
2）光线干净、背景简洁，按商品图逻辑拍
3）上身单注意：仪态自然、不夸张挑逗；按「电商详情图」标准，不按擦边短视频标准
4）不要额外拍摄订单未要求的暴露内容
5）有疑义先留言，再拍
```

### 6.2 商家临时加码尺度

```text
若商家通过留言/私下要求增加订单未写明的暴露内容：
请不要执行。回复「请以订单拍摄要求为准」，并 @ 运营。
超范围需求要么走平台变更（含佣金），要么拒绝。
```

### 6.3 交付话术（达人可复制给订单留言）

```text
素材已按订单要求上传，请验收。
如需补拍，请说明具体镜头（仍须在原订单约定范围内）。
```

## 7. 抖音场景（谨慎使用）

> 敏感品类 **不建议** 作为抖音冷私信主推内容。  
> 仅当对方已是达人、在站内/微信沟通时处理。若必须在抖音提及，用最低刺激表述。

### 7.1 抖音内点到为止（已互相关注/已回复）

```text
对了，平台偶尔有【贴身衣物类】寄拍，佣金更高，但完全自愿、需成年。
这类说明比较细，我在微信发边界清单更合适。不感兴趣忽略即可，不影响普通单。
```

### 7.2 禁止在抖音发送

```text
❌ 情趣、开档、诱惑、反差、裸感 等词堆砌
❌ 对比图、尺度示例图
❌ 「拍这个来钱快」
❌ 直接甩商品细节图
```

## 9. 管理端一键复制区（精简）

### 9.1 预告

```text
有一类【贴身衣物/内衣寄拍】，佣金常约普通衣 3～5 倍（以订单为准），需成年自愿。不接不影响普通单。想了解回「可以了解」；只要普通回「普通」。
```

### 9.2 边界确认

```text
特殊品类说明：可能含文胸等贴身款；拍摄分平铺/上身/是否露脸，以订单为准；佣金约 3～5 倍普通衣但以页面为准；不要求私单、不垫付、不超范围暴露。可随时不抢。回复「已知晓，可按边界接单」/「仅平铺」/「不接特殊品类」。
```

### 9.3 抢单前

```text
本单为贴身/特殊品类｜佣金¥__｜拍摄：平铺/上身/露脸__｜请确认已满18且自愿。回「确认抢单」或「放弃」。放弃无惩罚。
```

### 9.4 拒单安抚

```text
已记录不推送特殊品类，普通单照常。需要时你再说「可了解」即可。
```

### 9.5 安全句

```text
全程平台内交付。不会要求你先转账。遇到加微信私单、加钱加尺度，直接拒绝并告诉运营。
```

## 12. 合规备忘（给负责人）

1. 内容应定位为 **合法成人商品的电商拍摄**，不是色情服务中介  
2. 达人侧强调 **劳动报酬按单结算**，不是「打赏/陪伴」  
3. 素材审核按电商图规范，拒绝违规暴露  
4. 保留达人「已知晓/仅平铺/不接」回复记录，降低纠纷  
5. 若涉及更极端款式，先法务评估再上架，不靠话术硬盖
