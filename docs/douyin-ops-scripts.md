# 蓝鹰寄拍 · 抖音运营话术库（管理端可复制版）

> **用途**：供管理端运营人员一键复制  
> **场景**：抖音私信招新 → 对方回复后跟进 → 加微信 → 引导访问网页 / 安装安卓 App  
> **原则**：合规优先、低刺激话术、先建立信任再导流、不承诺收益

---

## 0. 使用前必读（抖音风控）

### 0.1 运营纪律（必须遵守）

| 规则 | 说明 |
| --- | --- |
| 先互动后导流 | 首条私信**不发链接、不发微信号、不发二维码、不发 App 下载** |
| 等对方主动回 | 对方回复后，再进入「说明 → 加联系方式 → 发入口」 |
| 单日限量 | 同一账号避免高频同质私信；建议分时段、换话术、控数量 |
| 内容相关 | 只私信穿搭/好物/居家/学生/宝妈等相关账号，减少举报 |
| 不诱导关注变现 | 不说「关注领单」「私我日入」「加群躺赚」 |
| 不碰违规品类 | 不涉及刷单、返利、投资、医美整容承诺、色情擦边 |
| 统一身份 | 对外固定「蓝鹰寄拍官方/运营」，不冒充个人宝妈骗信任后硬推 |
| 记录可追溯 | 管理端记录：谁发的、何时发的、对方是否回复、是否加微、是否注册 |

### 0.2 高风险词（尽量避免）

```text
日入 / 月入过万 / 躺赚 / 稳赚 / 保底 / 提成很高
加微信 / 加V / 威信 / 薇信 / 扣扣 / 扫码
点链接 / 点开领取 / 下载就赚钱
刷单 / 垫付 / 先交保证金 / 培训费
免费领 / 限时名额马上没 / 不加就没了
```

### 0.3 低风险替代表达

| 高风险说法 | 建议替换 |
| --- | --- |
| 加微信详聊 | 方便的话留个联系方式，我把入驻说明发你 |
| 点这个链接赚钱 | 入口我发你，你自己打开看介绍再决定 |
| 日入 300+ | 按单结算，单笔以订单显示为准 |
| 单子多到爆 | 有合适单可以接，前期先帮你跑通流程 |
| 马上下载 App | 安卓的话我发安装说明，你按步骤自己装 |
| 不回就没机会 | 不着急，你方便再看 |

### 0.4 推荐转化路径（标准 SOP）

```text
阶段A 首条破冰私信（无链接、无微信、无下载）
   ↓ 对方回复任意内容
阶段B 简短说明 + 确认意向（仍可不发外链）
   ↓ 对方表示想了解 / 想试试
阶段C 邀约留联系方式（微信）——用低风险措辞
   ↓ 已加微信
阶段D 微信内发完整说明 + 网页入口 / App 安装说明
   ↓ 引导注册与完善资料
阶段E 跟进审核 / 首单辅导
```

**关键原则：抖音只负责“聊开”；注册、链接、App 尽量放到微信完成。**

## 1. 阶段 A｜首条破冰私信（仅 1 条机会）

> 要求：短、像人话、无外链、无微信号、以「回一个词」为行动点。

### A1 通用（推荐默认）

```text
你好呀，看你主页挺适合做「在家寄拍」：商家把样品寄到手上，按要求拍完上传，验收通过后按单结算。比较适合时间比较碎的姐妹。我们是蓝鹰寄拍官方，正在找认真想了解的达人。想看说明的话回我「了解」就行～
```

### A2 学生向

```text
你好～如果课余想找个不跑店的灵活事，可以了解下「寄拍」：样品寄到你这，拍完上传就行，按单结算。我们蓝鹰寄拍在招女生达人，不强迫、不收费了解。有兴趣回「了解」～
```

### A3 宝妈向

```text
宝妈你好～有个在家就能做的寄拍协作：样品寄到家，按要求拍完上传，验收后结算。适合见缝插针的时间。我们是蓝鹰寄拍，只找愿意认真了解的姐妹。想看怎么开始回「了解」～
```

### A4 穿搭/好物向

```text
你好，看你平时就爱拍东西，其实和「寄拍协作」挺像：商家寄样品，你按要求出图，验收后结算。我们蓝鹰寄拍在找拍摄达人。想看具体说明回「了解」就好～
```

### A5 更短版

```text
你好～蓝鹰寄拍在找在家拍摄的女生达人：商家寄样、拍摄上传、验收结算。想了解回「了解」，我按你情况说～
```

### A6 更稳妥（风控最保守）

```text
你好，我们是蓝鹰寄拍平台运营。平台做的是商家与拍摄达人的协作对接，流程都在平台内完成。若你有兴趣了解是否适合自己，可以回「了解」，我再说明，不打扰的话忽略即可。
```

## 2. 阶段 B｜对方已回复：先稳住，再推进

> 对方回了「了解 / 怎么做 / 要钱吗 / 单子多吗」等，**先答疑 1～2 句，再邀约留联系方式**。  
> 此阶段仍建议：抖音内少发外链。

### B1 对方回「了解 / 1 / 好的」

```text
好的～先说清楚三点：
1）入驻了解免费（不收培训费/加盟费）
2）模式是商家寄样→你拍摄上传→验收后按单结算
3）不保证每天都有单，但流程清楚，适合先跑通1单

你现在更方便看手机网页，还是安卓手机？我按你的方式发说明。
另外为了把入口和步骤发完整（抖音里容易发不全），你方便留个微信号吗？我备注「蓝鹰寄拍」加你。
```

### B2 对方回「是什么 / 怎么赚钱」

```text
简单说：不是让你转发任务，是真实寄样拍摄协作。
商家把样品寄给你 → 你按要求拍照/拍视频并上传 → 样品寄回 → 商家验收通过后，佣金按订单金额入账，再申请提现。

你要是觉得可以了解，我把完整入驻步骤发你。方便留个微信吗？我发网页入口/安卓安装说明（抖音里链接不稳定）。
```

### B3 对方回「要交钱吗 / 是不是骗子」

```text
理解你谨慎～我们说明白：
· 了解和入驻说明不收费
· 不要求你先垫钱给个人
· 订单、验收、结算都在平台流程里走，可追踪

你要是愿意看，我把平台介绍和入口发你，你自己打开看再决定。方便用微信接收吗？我备注官方身份加你。
```

### B4 对方回「单子多吗 / 能赚多少」

```text
实话实说：佣金看每笔订单显示金额，不是口头承诺月入。
平台前期更适合愿意先完善资料、认真交付的人；单量会逐步上，不拿“暴富”吸引你。

如果你接受「按单结算、先跑流程」，我再发入驻方式。方便留微信吗？材料比较完整，抖音一次发不完。
```

### B5 对方回「我是学生 / 宝妈，有时间吗」

```text
可以的，很多是课余/带娃间隙做，不是坐班打卡。
一般是有单再拍，拍完上传寄回即可；接单节奏自己把控（也受等级额度限制，新手先稳）。

我按你的身份发更合适的说明。你方便留个微信吗？我发入口，你自己注册看。
```

### B6 对方犹豫「再看看 / 不急」

```text
没关系，不着急～
你要是之后想看，随时回「了解」。
我也可以先发一段文字说明（不带链接），你看完再决定要不要留联系方式。
```

### B6 补充：仅文字说明（仍不发链接）

```text
【蓝鹰寄拍·文字说明】
角色：拍摄达人
流程：完善资料+实名 → 审核通过 → 抢单 → 收样品 → 拍摄上传 → 寄回 → 验收结算 → 申请提现
适合：学生/宝妈/居家女生，会手机拍照、能收发快递
说明：按单结算；不承诺固定收入；平台内流程可追踪

若要获取网页入口或安卓安装方式，回「要入口」，我再联系你发。
```

## 3. 阶段 C｜吸引对方留下微信 / 联系方式

> **目标**：让对方主动留微信号，或同意你加她。  
> **话术要点**：给理由（材料长、链接在抖音不稳定、要发安装包说明），降低防备。

### C1 标准邀约（推荐）

```text
好的，那我把「入驻步骤 + 网页入口 + 安卓安装说明」整理发你。
抖音里外链经常发不出去/打不开，所以一般改微信发完整版。

你可以直接发微信号给我，我备注【蓝鹰寄拍-你的昵称】添加；
或者你加我，我把我的号发你（二选一你方便哪个）。
```

### C2 更软、更低压力

```text
材料有点长，还要区分网页版和安卓版，抖音一次说不清。
你要是方便，留个联系方式，我发你自己看；不方便也没关系，我可以继续在这用文字答疑。
```

### C3 给选择（提高回复率）

```text
为了发入口方便，你选一个就行：
① 你发微信号，我加你
② 我发客服号，你通过后我发资料
③ 暂时不加，先在这问

回 1 / 2 / 3 就行～
```

### C4 对方不愿加微信

```text
完全理解～那我们先在这沟通。
你更想先看：入驻要什么资料、怎么接单、还是结算怎么走？
等你觉得OK了，再拿入口也不迟。
```

### C5 对方问「为什么要加微信」

```text
主要三个原因：
1）抖音对外部入口限制多，网页/安装说明经常发不全
2）后面审核、资料问题方便一对一协助（你也可以不回）
3）我们会发官方说明，不要求你转账给个人

你只用来接收资料也行，不想聊可以设置免打扰。
```

### C6 对方同意后，你发客服微信号

```text
好的，这是我们对接号：【在此填写微信号】
请备注：寄拍+抖音昵称
通过后我会发：
1）平台介绍
2）网页入口
3）安卓安装说明（如需要）
添加时认准备注，谨防仿冒。
```

### C7 安全提示（建议每次加微前后带一句）

```text
提醒：我们不会让你先转账、不会收保证金/培训费。若有人私聊让你付款，请立刻停止并告诉我。
```

## 4. 阶段 D｜已加微信后：导流网页 / 安卓 App

> **从这里开始可以发链接与安装说明。**  
> 运营在管理端替换：`【网页链接】` `【安卓下载链接】` `【客服微信】` `【有效期说明】`

### 4.1 加微成功 · 开场（必发）

```text
你好，我是蓝鹰寄拍运营，抖音沟通的那位。
先发三样，你按顺序看就行：

① 一分钟了解平台
商家寄样 → 你拍摄上传 → 寄回样品 → 验收通过后按单结算 → 申请提现

② 入驻需要
头像昵称、收货地址、作品集（至少6张）、实名信息（用于认证与提现）

③ 重要说明
· 了解/入驻说明免费
· 不保证固定收入
· 请只通过下方官方入口注册

你更方便用【手机网页】还是【安卓App】？回「网页」或「安卓」。
```

### 4.2 引导网页版（H5 / 达人端）

#### D-Web-1 标准

```text
【网页入口】
请用手机浏览器打开：
【网页链接】

建议步骤：
1. 打开链接
2. 注册/登录达人账号
3. 完善资料与作品集
4. 提交实名认证
5. 等待审核通过后进入抢单

若打不开：换系统浏览器（不要用微信内置页也可再试一次），或把截图发我帮你看。
```

#### D-Web-2 对方说「打不开 / 空白页」

```text
别急，按这个排查：
1）复制链接到手机自带浏览器打开
2）检查网络（切换 WiFi/流量）
3）若仍不行，发我截图+手机型号，我给你备用入口或安卓方式
```

#### D-Web-3 引导收藏/回到入口

```text
入口建议收藏，避免以后找不到。
你注册好后把「注册用的手机号后四位」回我，我帮你看资料是否提交完整。
```

### 4.3 引导安卓 App

#### D-App-1 标准

```text
【安卓App】
安装说明：
1. 点击下载：【安卓下载链接】
2. 若提示「未知来源」，在系统设置里允许本次安装即可
3. 安装后打开 App，使用达人账号登录
4. 完善资料 → 实名 → 等审核 → 抢单

注意：
· 请从我们发给你的官方链接下载
· 不要从陌生转发链接安装
· 我们不会要你付款才能安装
```

#### D-App-2 对方只有安卓且担心安全

```text
理解～App 是达人端封装（方便手机使用），账号体系与网页一致。
你也可以先用网页完成注册和资料，后续再装 App。
更稳妥顺序：先网页注册 → 再决定是否装 App。
网页：【网页链接】
```

#### D-App-3 安装失败

```text
常见处理：
1）下载完成后点文件安装
2）允许安装未知应用（仅本次）
3）清理旧包后重装
4）仍失败：发手机品牌+系统版本，我给你网页版先用
网页备用：【网页链接】
```

#### D-App-4 对方是 iPhone

```text
目前达人端安卓App更完整；iPhone 建议先用手机网页：
【网页链接】
用 Safari 打开后，可「添加到主屏幕」当快捷方式用。
```

### 4.4 双入口一起发（对方说都行）

```text
都可以，按你习惯选一个：

【方式A·网页】更轻，先体验
【网页链接】

【方式B·安卓App】常用安卓更方便
【安卓下载链接】

建议：先网页注册完善资料，安卓用户再装 App 登录同一账号即可。
```

## 5. 阶段 E｜注册后跟进（提高留存/首单）

### E1 询问是否注册成功

```text
你那边打开了吗？
如果已注册，回我：
1）是否已提交作品集
2）是否已提交实名
我帮你对一下还差哪步（差一步都过不了抢单）。
```

### E2 资料不完整

```text
审核前请确认：
□ 头像昵称
□ 收货省市区+详细地址+收件人电话
□ 作品集 ≥ 6 张（清晰即可）
□ 实名与支付宝信息按页面填写

缺哪项直接说，我按项教你。
```

### E3 审核中等待

```text
资料已提交的话耐心等审核即可。
通过后你就能进抢单大厅。
期间有问题随时发截图，我在这协助。
```

### E4 审核通过 · 首单激励（不夸大）

```text
恭喜通过～下一步很重要：先认真完成 1 单，把流程跑熟。
建议：
1）先看清拍摄要求再接
2）收货、拍摄、上传、寄回都在订单里操作
3）有异常及时在订单说明，不要私下答应改价/改需求

你现在打开大厅能看到单吗？看不到发截图我帮你看。
```

### E5 长时间未注册

```text
嗨，前两天发的入口你还有看吗？
不着急注册，但链接若过期我可以重发。
回「网页」或「安卓」我再发一次官方入口。
```
