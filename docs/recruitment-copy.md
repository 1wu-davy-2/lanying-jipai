# 蓝鹰寄拍 · 达人招新物料包

> 适用阶段：平台前期招新  
> 目标人群：女大学生、宝妈、待业/无主业女性、想做副业的居家人群

## 一、一句话定位

**蓝鹰寄拍：商家寄样品给你，你在家拍完上传，验收通过就结算佣金。**

适合：

- 学生党：课余时间可做

- 「躺赚」「日入过千」「保证月入 X 万」

### 4.3 佣金怎么说（推荐口径）

> 真实系统逻辑：佣金由商家发单时填写；验收通过后入账；MVP 阶段平台不做抽佣扣减。  
> 达人等级会限制「同时进行中订单数」和「单笔佣金上限」。

**对外话术（稳妥）：**

```text
【关于佣金】
· 佣金按订单显示金额结算，不是口头说了算
· 商家验收通过后，佣金进入你的可提现余额
· 你可以在平台发起提现申请，审核通过后按平台流程处理
· 不同订单佣金不同，常见是按样品拍摄难度、件数、要求来定
· 新手一般从较低门槛单开始，先把流程跑熟，再接更高佣金单

【等级与接单额度】（可对认真询问的人说明）
L1 新星达人：刚起步，同时可接 1 单，单笔上限约 ¥300
L2 稳定达人：完成 5 单后，同时可接 2 单，单笔上限约 ¥800
L3 进阶达人：完成 20 单后，同时可接 3 单，单笔上限约 ¥1,500
更高等级随完成单数提升，额度更大

说明：等级是为了保护新手节奏和交付质量，不是卡人，而是让你稳步接单。
```

**不要这样说：**

```text
❌ 保底月入 8000
❌ 一单最少 500，随便拍拍就行
❌ 我们抽成很少，你能拿 90%（MVP 实际可不抽佣，但别编复杂故事）
❌ 单子多到抢不过来
```

### 4.5 平台保证怎么说（信任点）

```text
【平台能保证什么】
1. 流程可追踪：订单从发布、抢单、寄出、拍摄、寄回、验收，状态都在系统里
2. 抢单规则公平：一单只能被一人抢走，避免私下扯皮
3. 结算有依据：验收通过后按订单佣金入账，有资金流水可查
4. 争议可处理：商家不通过时可进入争议，由平台介入仲裁
5. 提现有审核：提现申请走平台审核流程，不是私下转账口头承诺

【平台不保证什么】
· 不保证每天都有单
· 不保证每单都能过审（拍摄要按要求来）
· 不保证固定月收入
我们更强调：规则清楚、过程可查、结算可追溯。
```

### 4.6 入驻要求（降低顾虑）

```text
【入驻需要什么】
1. 基本资料：头像、昵称
2. 收货信息：省市区 + 详细地址 + 收件人 + 手机号（样品要寄到你）
3. 作品集：至少 6 张作品照（手机拍的好物/穿搭/静物都可以，先证明你会拍）
4. 实名认证：真实姓名、身份证、支付宝账号（用于后续提现）
5. 审核通过后，才能正式抢单

新手提示：
作品集不用影楼级，清晰、光线正常、构图干净就行。
先过审核，再在真实订单里练手。
```

## 七、FAQ 速答（私信被追问时）

| 问题 | 建议回答 |
| --- | --- |
| 要交钱吗？ | 入驻不收加盟费/保证金话术请按你们实际政策；若无收费就明确说「入驻不收费」。 |
| 会不会骗？ | 订单、验收、结算都在平台流程里，提现走审核，不是让你私下打款给个人。 |
| 没拍过行吗？ | 可以，先准备 6 张作品集过审，从简单单开始。 |
| 多久能提现？ | 验收通过后佣金入账，再按平台提现审核流程处理（不要承诺「秒到」）。 |
| 单子多吗？ | 前期招新阶段，单量会逐步起来；先入驻跑通流程更重要。 |
| 样品坏了怎么办？ | 按订单要求保管与寄回；异常及时在订单内说明，由平台/商家按流程处理。 |
| 一定要出镜吗？ | 看订单要求，有的是静物拍，有的可能需要上身展示，以订单说明为准。 |

> 若你们**入驻完全免费**，请在所有话术里统一加一句：「入驻免费，不收培训费。」  
> 这是女性副业人群最敏感的信任点。
