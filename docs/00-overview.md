# 寄拍接单平台 —— 总体方案

## 1. 项目目标

一个「寄拍」业务的接单/管理平台。核心闭环：**商家发单 → 达人抢单 → 寄件 → 拍摄 → 寄回 → 商家验收 → 平台结算佣金 → 达人提现（人工转账确认）**。

## 2. 角色

| 角色 | 说明 |
|---|---|
| 商家（发单方） | 发布寄拍需求（样品、佣金、拍摄要求），寄出/接收样品，验收拍摄素材，验收后触发结算 |
| 达人（接单方，模特/摄影师） | 浏览抢单大厅、抢单、收货拍摄、上传素材、寄回样品，申请提现 |
| 平台管理员 | 用户管理、达人实名审核、订单监控、争议仲裁 |
| 交易员（管理员的子职能，MVP 阶段不单独建角色，用权限位区分） | 审核提现申请，线下完成支付宝转账后，把转账流水号登记回系统，系统才把余额从「冻结」标记为「已提现」 |

> MVP 阶段不接入微信支付/支付宝支付网关。达人注册时登记支付宝账号，提现是「系统记账 + 人工转账 + 登记流水号确认」的模式，见 [01-business-flow.md](01-business-flow.md) 第 4 节。

## 3. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | React 18 + TypeScript + Vite | 主流、生态好、构建快 |
| UI 组件库 | Ant Design 5 | 中后台/表单/审批流场景组件齐全（Table、Steps、Form），中文生态成熟 |
| 前端状态 | Zustand（登录态/全局态）+ TanStack Query（服务端数据缓存与请求） | 比 Redux 轻量，CRUD 场景下减少样板代码 |
| 路由 | React Router v6 | 单 SPA 内按角色分路由组 + 路由守卫 |
| 后端 | Python 3.11 + FastAPI | 异步、自动生成 OpenAPI/Swagger 文档、类型友好、和 Pydantic 结合好 |
| ORM/迁移 | SQLAlchemy 2.0 + Alembic | 迁移可追溯，适合团队协作 |
| 数据库 | MariaDB 11.4.12 | 按你现有环境确定 |
| 鉴权 | JWT（access + refresh） | 无状态，适合前后端分离 |
| 部署 | Nginx + Gunicorn(uvicorn worker) + systemd + Linux 云服务器 | 标准、可控、不依赖容器编排也能跑，后续可平滑迁移 Docker |
| 文件存储（MVP） | 服务器本地磁盘 + Nginx 静态托管 | 先跑起来，标注未来迁移对象存储（OSS/COS）的扩展点 |

```
                        │      用户浏览器       │
                        └──────────┬───────────┘
                                   │ HTTPS
                        ┌──────────▼───────────┐
                        │   Nginx (反向代理)     │
                        │  - 80/443 对外          │
                        │  - / 前端静态文件        │
                        │  - /api/* → 后端        │
                        │  - /uploads/* 静态文件   │
                        └───┬───────────────┬───┘
                            │               │
                 ┌──────────▼───┐   ┌───────▼────────┐
                 │ React SPA    │   │ Gunicorn +      │
                 │ (dist 静态)   │   │ FastAPI (多进程) │
                 └──────────────┘   └───────┬────────┘
                                             │
                                     ┌───────▼────────┐
                                     │ MariaDB 11.4.12 │
                                     └────────────────┘
```
